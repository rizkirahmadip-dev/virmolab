Kriteria interaksi

JenisKriteria
Ikatan hidrogenDonor···akseptor ≤ 3,5 Å; H···akseptor ≤ 2,8 Å; sudut D–H···A ≥ 110° (tanpa atom H: hanya jarak D···A).
HidrofobikKarbon ligan yang hanya terikat C/H (atau Cl/Br/I) ↔ karbon protein yang hanya terikat C/H, ≤ 4,0 Å; satu kontak terdekat per residu.
π–πPusat cincin aromatik ≤ 5,5 Å; tumpuk: sudut bidang ≤ 30° dan offset ≤ 3,0 Å; bentuk T: sudut ≥ 60°.
π–kationPusat cincin ↔ kation (LYS NZ, ARG NE/NH1/NH2, HIS terprotonasi ganda, amina ligan bermuatan) ≤ 6,0 Å, offset lateral ≤ 2,0 Å.
Jembatan garamGugus bermuatan berlawanan (ASP/GLU/ujung-C ↔ LYS/ARG/HIS+; gugus ionik ligan) ≤ 4,0 Å.
Ikatan halogenC–X···A (X = Cl, Br, I; A = O, N, S): X···A ≤ 3,5 Å, sudut C–X···A ≥ 140°.
Koordinasi logamIon logam ↔ O/N/S ligan ≤ 2,8 Å.
van der WaalsResidu tanpa interaksi lain dengan atom berat ≤ 4,2 Å dari ligan (untuk diagram 2D).

Besaran turunan

  • Ki perkiraan = exp(ΔG / RT), R = 1,987207 × 10⁻³ kcal mol⁻¹ K⁻¹, T = 298,15 K.
  • Efisiensi ligan (LE) = −ΔG / jumlah atom berat (kcal/mol per atom berat).
  • RMSD redocking: atom berat, tanpa penjajaran (pose dan kristal di kerangka koordinat reseptor yang sama), minimum atas semua pemetaan simetri molekul; dihitung pada graf tanpa orde ikatan agar tidak terpengaruh protonasi. Valid bila ≤ 2,0 Å.
  • RMSD ref (AutoDock): RMSD terhadap koordinat ligan masukan, dari berkas .dlg.
