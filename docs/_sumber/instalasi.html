Instalasi

VirmoDock berjalan di Windows 10/11 64-bit tanpa perlu Python, WSL, MGLTools, atau program lain. Semua mesin docking sudah disertakan.

Pilihan A — Installer (disarankan)

  1. Jalankan VirmoDock-Setup-x.y.z.exe. Bila Windows SmartScreen muncul (“Windows protected your PC”), klik More info › Run anyway — installer belum ditandatangani sertifikat berbayar.
  2. Pilih folder instalasi (bawaan: C:\Program Files\VirmoDock, atau folder pengguna bila tanpa hak admin).
  3. Pilih tugas tambahan: ikon Desktop, kaitkan berkas .pdbqt/.vmdbackup dengan VirmoDock (opsional).
  4. Klik Pasang, lalu Selesai untuk membuka VirmoDock.

Hapus pemasangan lewat Settings › Apps › VirmoDock › Uninstall. Proyek di folder kerja (bawaan Documents\VirmoDock) tidak ikut terhapus.

Pilihan B — Versi portable (tanpa instalasi)

  1. Ekstrak VirmoDock-Portable-x.y.z.zip ke folder mana saja (mis. flashdisk atau D:\VirmoDock). Hindari folder yang dilindungi seperti C:\Program Files.
  2. Jalankan VirmoDock.exe.

Versi portable menyimpan pengaturan di data\pengaturan.ini dan proyek bawaan di Proyek\ di dalam folder itu sendiri — tidak menyentuh registry. Penanda portable adalah berkas portable.flag; jangan dihapus.

Pertama kali dibuka

  1. Pemeriksaan sistem: GPU, driver, CPU, RAM, dan mode docking bawaan (GPU bila OpenCL tersedia, selain itu CPU). Bila GPU ada tetapi OpenCL tidak, ikuti panduan driver yang muncul — lihat Setup GPU.
  2. Software pendukung: PyMOL, ChimeraX, Discovery Studio Visualizer dideteksi untuk tombol “Buka di…”. Semuanya opsional.
  3. Folder kerja: tempat proyek baru disimpan.

Deteksi GPU dijalankan ulang setiap kali VirmoDock dibuka, jadi setelah pindah laptop atau memperbarui driver tidak perlu mengatur apa pun. Wizard bisa dibuka lagi lewat Tools › Cek sistem / GPU.
