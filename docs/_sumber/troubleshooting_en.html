Troubleshooting

Common problems and how to get past them. Every error is also explained in the Messages panel, together with the step it suggests.

First step: run Tools › Component self-test…. VirmoLab checks every docking engine, Open Babel, RDKit/Meeko, a small Vina docking run, GPU detection, ligand properties, statistics, PoseBusters, Excel export, the interface themes, the WSL tool scripts, and the network pharmacology workflow (64 checks), then shows which ones failed. From the command line: VirmoLab.exe --uji-mandiri result.json.
SymptomCause & remedy
Status bar: “OpenCL not available — CPU mode”An old GPU driver, or the one Windows ships. Update the driver (GPU setup), restart, and open VirmoLab again.
Messages panel: “AutoDock-GPU could not use the GPU (OpenCL error)”The job has already continued with Vina. Update the driver; if it still fails, use Vina.
The 3D viewport is black or emptyThe graphics driver does not support WebGL. Update it. Meanwhile, run VirmoLab with software rendering: make a shortcut whose target is VirmoLab.exe --disable-gpu.
Import from RCSB or PubChem failsCheck the internet connection; a campus or office network with a proxy can block it. Download the PDB/SDF file through a browser and open it with File › Open structure file… (Ctrl+O).
“ID … not found in RCSB PDB”A mistyped ID, or a structure that exists only as mmCIF (VirmoLab tries mmCIF automatically).
Receptor preparation drops many residuesResidues with missing atoms, common in flexible loops. If they sit near the active site, pick another PDB structure with better resolution, or repair the structure in other software first.
Receptor preparation fails in MeekoVirmoLab falls back to Open Babel on its own. If that fails too, try keeping only one chain and removing ligands and additives.
Ligand: “> 32 torsions (AutoDock-GPU limit)”Run that ligand with the Vina engine.
Ligand: “atom type not supported by AutoDock”It contains an element such as B or Si, for which AutoDock4 has no parameters. Replace the ligand, or use Vina with care.
Grid warning “exceeds 126 points”The box is too large for 0.375 Å spacing. Raise the spacing (to 0.5–0.6 Å, say) or shrink the box. The “Whole protein (blind docking)” button sets the spacing by itself.
Redocking validation gives RMSD > 2 ÅTry: centring the box on the native ligand, more runs (the Thorough preset), or another engine. If the native ligand has a metal ion or structural waters in the active site, keep them during receptor preparation.
Installing advanced tools: “WSL refused to start … ERROR_NO_SYSTEM_RESOURCES”Windows is short of resources for the WSL virtual machine, often while a camera or video application is open. Close it, wait a moment, then click Check again. Lowering the WSL memory limit does not help.
Installing advanced tools: “Internet connection lost or blocked”Click Install again; downloads that already finished are not repeated. On a campus or office network, set the proxy inside Ubuntu (export HTTPS_PROXY=http://proxy:port in ~/.bashrc).
Installing advanced tools: “WSL disk full”, or not enough disk spaceThe WSL virtual disk normally lives on drive C:. Free space there, then click Install again. The GPU & RBFE package needs about 24 GB free during installation, the co-folding package about 22 GB.
Installing advanced tools: the distribution “runs on WSL 1”Click Copy command, run wsl --set-version <distro> 2 in PowerShell, then Check again.
The Uni-Dock button in the docking panel is greyed outUni-Dock is not installed, or the computer has no NVIDIA GPU. Install the GPU & RBFE docking package through Tools › Install advanced tools (WSL)….
Docking stops when the laptop sleepsSet Windows not to sleep while plugged in. An interrupted job is marked Paused and can be resumed.
Antivirus deletes or blocks autodock_gpu.exe or vina.exeUnsigned scientific programs are sometimes treated as suspicious. Add the VirmoLab folder to the antivirus exclusions, then install again.
Everything is too small or too largeVirmoLab follows the Windows scale (Settings › Display › Scale). Panels can be hidden through View › Panels; the workspaces (Ctrl+1/2/3) show only the panels you need; View › Reset layout restores the default arrangement.
The window is invisible after unplugging a second monitorIt is centred on the primary screen automatically at startup. If it stays hidden: Alt+Space › Move.

Reporting a problem

Help › Report a problem or send feedback… assembles a text holding your description, system information, and the most recent log. Read it through, click Copy, then send it by email or through the project's Issues page. VirmoLab sends nothing by itself. The log folder: Help › Open log folder.
