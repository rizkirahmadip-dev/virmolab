Moving to another laptop

Carry settings, parameter presets, window layout, and projects to another laptop in a single file.

On the old laptop

  1. Open the project you want to take with you (optional).
  2. File › Move to another laptop › Export settings and projects…
  3. Answer Yes if the project currently open should be included.
  4. Save the VirmoLab_YYYYMMDDHH.vmdbackup file and copy it to the new laptop (USB stick, Google Drive, and so on).

The backup holds every setting (theme, layout, custom presets, working folder, the locations of PyMOL/ChimeraX/DSV) and — when chosen — the whole project folder (receptor, ligands, grid, results). Grid maps are copied as well, so docking can continue straight away.

On the new laptop

  1. Install VirmoLab (installer or portable build) — see Installation.
  2. File › Move to another laptop › Import settings and projects…, then choose the .vmdbackup file.
  3. Projects are extracted into the working folder; choose Yes to open one immediately.
Paths that do not exist on the new laptop (a working folder on drive D:, say, or the location of PyMOL) are ignored and noted in the Messages panel; VirmoLab falls back to its defaults and detects the companion software again. The GPU is also detected again: if the new laptop has no OpenCL GPU, the engine switches to Vina on the CPU.

Without exporting

  • The portable build: copy the whole portable folder, including data\ and Proyek\ — the settings travel with it.
  • A single project: copy the Name.vmd folder, then File › Open project… on the new laptop. Unfinished jobs appear as Paused and can be resumed.
