GPU setup

AutoDock-GPU in VirmoLab uses OpenCL, so it runs on NVIDIA, AMD, and Intel GPUs without CUDA or WSL. With no GPU at all, VirmoLab still works in full using AutoDock Vina on the CPU.

Reading the status bar

Status barMeaningWhat to do
● NVIDIA GeForce … · 6 GB · driver 610.74 · OpenCLThe GPU is ready for AutoDock-GPU.Nothing.
● … · OpenCL not available — CPU modeThe GPU is visible but its driver provides no OpenCL.Update the driver (below).
● No GPU — CPU mode (Vina)No usable GPU was found.Use Vina; set exhaustiveness to match the time you have.

Check again at any time through Tools › Check system and GPU…. The device choice (GPU or CPU) sits in step 4 Run, under Engine and device. If the laptop has more than one OpenCL GPU (Intel plus NVIDIA, for instance), all of them appear in the list; the one with the most VRAM is chosen by default.

Installing or updating the driver

NVIDIA

  1. Open nvidia.com/Download and choose your laptop's GPU series and model.
  2. Download the Game Ready or Studio Driver, run it, and choose the Express installation.
  3. Restart the laptop, then open VirmoLab again.

AMD

  1. Open amd.com › Drivers and choose Auto-Detect and Install.
  2. Run the installer, restart, then open VirmoLab again.

Intel (integrated graphics)

  1. Open the Intel Driver & Support Assistant.
  2. Install the recommended graphics update, restart, then open VirmoLab again.
Laptops with two GPUs (Intel plus NVIDIA, say): VirmoLab picks the discrete GPU, the one with the most VRAM. Keep the laptop plugged in and set the power mode to “Best performance” so the discrete GPU stays active.

When the GPU fails during docking

If AutoDock-GPU reports an OpenCL error — a kernel that will not compile, GPU memory exhausted, a broken driver — VirmoLab continues the job automatically with AutoDock Vina on the CPU and writes the reason into the Messages panel. The results stay valid; they only take longer. Update the driver and start a new job to use the GPU again.
