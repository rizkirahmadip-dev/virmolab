# Dokumen pengembangan

Catatan perencanaan dan prompt kerja. Tidak ikut dibundel ke installer; pengguna aplikasi
tidak perlu membacanya. Panduan untuk pengguna ada di `docs/` dan di menu Bantuan aplikasi.

| Berkas | Isi |
|---|---|
| `RENCANA_PENGEMBANGAN.md` | rencana fitur F1 sampai F12, dasar ilmiah, dan peta rilis 1.2 sampai 1.6 |
| `PROMPT_SISA.md` | prompt siap salin per fitur beserta Blok verifikasi wajib |
| `PROMPT_PENGEMBANGAN.md` | sketsa antarmuka tiap fitur ("UI F...") dan lampiran UI |
| `RENCANA_LENGKAP.md` | peta kerja awal sampai rilis 1.0, sebagian besar sudah selesai |
| `IDE_BARU.md` | daftar gagasan yang belum diputuskan |
| `RIWAYAT_PEMBERSIHAN.md` | catatan perapian repositori |
| `TANDA_TANGAN_KODE.md` | cara menandatangani installer (Authenticode) dan pilihan sertifikat |

Status versi dan peta berkas ada di `../../CATATAN_TAHAP2.md`.
